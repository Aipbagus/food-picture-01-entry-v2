# food-picture-01 entry

Entry for the make.fun bounty [food-picture-01](https://make.fun/bounty/food-picture-01):
a program that writes one food picture to `/output/entry.png`.

- `entry.png` — the food picture (1024x1024 JPEG, shrimp & egg ramen bowl)
- `main.py` — copies `entry.png` to `/output/entry.png` (no network, deterministic)

Run: `python3 main.py`
